Carry out an ADF test of Y, present (i) the estimated test equation, (ii) the \(t_{\text{ADF}}\) test statistic, 5% critical value and decision, and (iii) its \(p\)-value.

library(urca)    # For use of ur.df function
adf <- ur.df(Y, type = "trend", selectlags = "AIC")
p_adf <- punitroot(adf@teststat[1], trend = "ct", statistic = "t")
  • (i) test equation
  • (ii) test summary
  • (iii) \(p\)-value

The test equation is: \[\Delta Y_{t}=\beta_{0}+\beta_{1}t+\varphi Y_{t-1}+\sum^{p-1}_{k=1}\psi_{k} \Delta Y_{t-k}+U_{t}\] The hypotheses are: \[\begin{align} H_{0}:&\;\varphi=0& &\textsf{($Y_{t}$ has a unit root)}\\ H_{1}:&\;\varphi<0& &\textsf{($Y_{t}$ does not have a unit root)} \end{align}\] The number of lags of \(\Delta Y_{t}\) (i.e., \(p-1\)) is selected by an information criterion (AIC), where \(p\) is the order of the underlying AR model.

Specify and estimate an appropriate ARIMA(\(p,d,q\)) model for \(Y_{t}\).

  • Since first differencing is required for log CPI to be stationary, we need \(d=1\).
  • How to select \((p,q)\)? \(\to\) Conduct a grid search for \(p=0,\dots,4\) and \(q=0,\dots,4\)

Code Structure

  • Set up container matrices for AICc values (AICc) and Ljung-Box test \(p\)-values (LBp)

  • For each \((p,q)\) combination:

    • Fit the ARIMA(\(p,1,q\)) model with Arima() function, and extract AICc

    • Extract the Ljung-Box \(p\)-values with Box.test() function

  • Choose the model with the lowest AICc, and verify that its Ljung-Box \(H_{0}\) (no autocorrelation) is not rejected.

Exercise 1(c)

Specify and estimate an appropriate ARIMA(\(p,d,q\)) model for \(Y_{t}\).

  • Since first differencing is required for log CPI to be stationary, we need \(d=1\).
  • How to select \((p,q)\)? \(\to\) Conduct a grid search for \(p=0,\dots,4\) and \(q=0,\dots,4\)
library(forecast)

pmax <- 4
qmax <- 4

LBp <- matrix(nrow=pmax+1, ncol=qmax+1)
rownames(LBp) <- paste0("p=", 0:pmax)
colnames(LBp) <- paste0("q=", 0:qmax)
AICc <- LBp

for (p in 0:pmax){
  for (q in 0:qmax){
    eq <- Arima(DY, order=c(p,0,q))
    LBp[p+1,q+1] <- Box.test(eq$residuals, lag = 8, 
                             type = "Ljung-Box", fitdf = p+q)$p.value
    AICc[p+1,q+1] <- eq$aicc
  }  
}

Exercise 1(c)

Model the linear trend using the observation indices \(t=1,2,\dots,n\).

Combining a difference and a linear trend in the model requires some careful interpretation - write out the model in equation form and interpret the coefficients.

  • ARIMA(1,0,3) on \(\Delta Y_{t}\)
  • ARIMA(1,1,3) on \(Y_{t}\)
  • Comments on Forecasting

To estimate the ARIMA(1,0,3) model for \(\Delta Y_{t}\), with that difference already taken in computing DY:

eq_a <- Arima(DY, order = c(1,0,3))
print(round(eq_a$coef,4))
      ar1       ma1       ma2       ma3 intercept 
   0.8316   -0.6377    0.2380    0.1276    0.0120

In equation form, this estimated model can be written as:

\[\begin{align} \Delta Y_{t}&=0.0120 +\widehat{\Delta Z}_{t}\\ \widehat{\Delta Z}_{t}&=0.8316\widehat{\Delta Z}_{t-1}+\widehat{U}_{t}-0.6377\widehat{U}_{t-1}+0.2380\widehat{U}_{t-2}+0.1276\widehat{U}_{t-3} \end{align}\]

The intercept of the model, \(\widehat{\beta}_{1}=0.0120\), implies the estimated mean rate of inflation is \(0.0120\), or \(1.2\%\) per quarter (this is a quarterly time series).

The same model may be estimated as an ARIMA(\(1,1,3\)) model for \(Y_{t}\):

eq_b <- Arima(Y, order = c(1,1,3), include.drift = TRUE)
print(round(eq_b$coef,4))
    ar1     ma1     ma2     ma3   drift 
 0.8316 -0.6377  0.2380  0.1276  0.0120

\[\begin{align} Y_{t}&=0.0120t +\widehat{Z}_{t}\\ \widehat{\Delta Z}_{t}&=0.8316\widehat{\Delta Z}_{t-1}+\widehat{U}_{t}-0.6377\widehat{U}_{t-1}+0.2380\widehat{U}_{t-2}+0.1276\widehat{U}_{t-3} \end{align}\]

Note

  • include.drift = TRUE option is necessary for the inclusion of \(\beta_{1}\) when the differencing is specified under order = c(1,1,3) rather than taking the difference beforehand and included in the model as DY.
  • It is called “drift” because a constant in a first-differenced process corresponds to a linear trend in the level of \(Y_{t}\).
  • Alternatively, replicating this with xreg argument:
t <- 1:length(Y)
eq_b_xreg <- Arima(Y, order = c(1,1,3), xreg = t)
print(round(eq_b_xreg$coef,4))
    ar1     ma1     ma2     ma3    xreg 
 0.8316 -0.6377  0.2380  0.1276  0.0120 
print(round(eq_a$coef,4))
      ar1       ma1       ma2       ma3 intercept 
   0.8316   -0.6377    0.2380    0.1276    0.0120 
print(round(eq_b$coef,4))
    ar1     ma1     ma2     ma3   drift 
 0.8316 -0.6377  0.2380  0.1276  0.0120
  • The two approaches are equivalent for estimation, as can be seen from these coefficient estimates. There is a difference, however, between the two when it comes to forecasting.
    • The ARMA(1,3) model on \(\Delta Y_{t}\) (DY) will generate forecasts for \(\Delta Y_{t}\) (inflation), while the second is model for \(Y_{t}\) (Y, log CPI). \(\to\) We will demonstrate this in part (e).
  • Neither is necessarily better/worse, it just depends on the intended purpose.

Exercise 1(d)

We start from the trend model with observation indices (\(t\)): \[\begin{align} Y_{t}&=\mathbb{E}(Y_{t})+Z_{t}\\ \textsf{where}\quad \mathbb{E}(Y_{t})&=\beta_{0}+\textcolor{purple}{\beta_{1}}t & &\textsf{(Trend model with observation indices)}\\ \mathbb{E}(Y_{t})&=\beta^{*}_{0}+\textcolor{teal}{\beta^{*}_{1}}\text{Time}_{t} & &\textsf{(Trend model with observation dates)} \end{align}\]

Question: How are \(\textcolor{purple}{\beta_{1}}\) and \(\textcolor{teal}{\beta^{*}_{1}}\) related? \(\to\) Intuitively, with quarterly data \(\beta_{1}=0.25\beta^{*}_{1}\).

  • We start with \(\textcolor{teal}{\text{Time}_{t}=1945.75+0.25t}\).
  • Then plugging this into the trend model with observation dates: \[\begin{align} Y_{t}&=\beta_{0}^*+\beta_{1}^{*}\textcolor{teal}{\text{Time}_{t}}+Z_{t}\\ &=\beta_{0}^*+\beta_{1}^{*}(\textcolor{teal}{1945.75+0.25t})+Z_{t}\\ &=\textcolor{purple}{(\beta_{0}^{*}+1945.75\beta_{1}^*)}+\textcolor{purple}{0.25\beta_{1}^{*}}t+Z_{t} \end{align}\]
  • Reading off the coefficients, we know \(\beta_{0}=\beta_{0}^{*}+1045.75\beta_{1}^{*}\) and \(\beta_{1}=0.25\beta_{1}^*\).

\(\widehat{\mathbb{E}}(\Delta Y_{n+1}\mid\mathscr{Y}_{n})\)

Forecast 2020Q1 \(\log(CPI_{2020Q1})\equiv Y_{2020Q1}\):

  • First we know that \(\Delta Y_{2020Q1}=Y_{2020Q1}-Y_{2019Q4}\).
  • On both sides take the conditional expectation based on data up to and including 2019Q4 (\(\mathscr{Y}_{2019Q4}\)): \[\mathbb{E}(\Delta Y_{2020Q1}\mid\mathscr{Y}_{2019Q4})=\mathbb{E}(Y_{2020Q1}\mid\mathscr{Y}_{2019Q4})-\mathbb{E}(Y_{2019Q4}\mid\mathscr{Y}_{2019Q4})\]
  • Since \(Y_{2019Q4}\in\mathscr{Y}_{2019Q4}\), \(\mathbb{E}(Y_{2019Q4}\mid\mathscr{Y}_{2019Q4})=Y_{2019Q4}\), thus adding hats gives: \[\widehat{\mathbb{E}}(Y_{2020Q1}\mid\mathscr{Y}_{2019Q4})=Y_{2019Q4}+\textcolor{purple}{\widehat{\mathbb{E}}(\Delta Y_{n+1}\mid\mathscr{Y}_{n})}\]

Question: Does the following hold? \[\color{blue}{\mathbb{E}[{CPI}_{2020Q1}\mid\mathscr{Y}_{2019Q4}]\overset{?}{=}\exp(\mathbb{E}[\log(CPI_{2020Q1})\mid \mathscr{Y}_{2019Q4}])}\]

Answer: No. This is because of Jensen’s inequality - since \(\exp(x)\) is convex: \[\mathbb{E}[\exp(\log(CPI_{2020Q1})\mid \mathscr{Y}_{2019Q4})]>\exp(\mathbb{E}[\log(CPI_{2020Q1})\mid \mathscr{Y}_{2019Q4}])\]

Remarks on the CPI forecasts:

Both approaches are approximations.

First approach: \(\widehat{CPI}_{2020Q1}=CPI_{2019Q4}\times (1+\color{purple}{\underbrace{\widehat{\text{inflation}}_{2020Q1}}_{\text{approximation}}})\)

Second approach: \(\widehat{CPI}_{2020Q1}=\exp(\hat{\mathbb{E}}[\log(CPI_{2020Q1})\mid\mathscr{Y}_{2019Q4}]\color{black}{)}\)

Thus this estimator is actually biased for the conditional mean \(\mathbb{E}[CPI_{2020Q1}\mid\mathscr{Y}_{2019Q4}]\): \[\mathbb{E}[CPI_{2020Q1}\mid\mathscr{Y}_{2019Q4}]>\exp(\mathbb{E}[\log(CPI_{2020Q1})\mid \mathscr{Y}_{2019Q4}])\]

Nevertheless, in practice and by research, simply taking the exponential tends to work well in providing a good approximation. So we will continue to take exponentials whenever required.

Exercise 2

Consider a time series model consisting of a trend equation and AR(p) equation: \[\begin{align} Y_{t}&=X_{t}^{\top}\beta +Z_{t}\\ Z_{t}&=\phi_{1}Z_{t-1}+\cdots+\phi_{p}Z_{t-p}+U_{t} \end{align}\]

The ADF equation for this model is: \[\Delta Y_{t}=\varphi Y_{t-1}+X_{t}^{\top}\beta^{*}+\sum^{p-1}_{k=1}\psi_{k}\Delta Y_{t-k}+U_{t}\] i.e. a regression of \(\Delta Y_{t}\) on

  • \(Y_{t-1}\): variable of interest for the ADF test;
  • \(X_{t}\): same set of deterministic variables as specified in the original model
  • lags \(1,\dots,p-1\) of \(\Delta Y_{t}\) (i.e. one fewer lag than in the original model).

Note the coefficients on \(X_{t}\) in the original model (\(\beta\)) differ from those in the ADF test equation (\(\beta^*\)).

Exercise 2

Consider a time series model consisting of a trend equation and AR(p) equation: \[\begin{align} Y_{t}&=X_{t}^{\top}\beta +Z_{t}\\ Z_{t}&=\phi_{1}Z_{t-1}+\cdots+\phi_{p}Z_{t-p}+U_{t} \end{align}\]

The ADF equation for this model is: \[\Delta Y_{t}=\varphi Y_{t-1}+X_{t}^{\top}\beta^{*}+\sum^{p-1}_{k=1}\psi_{k}\Delta Y_{t-k}+U_{t}\]

Note the coefficients on \(X_{t}\) in the original model (\(\beta\)) differ from those in the ADF test equation (\(\beta^*\)). \(\to\) How are these coefficients related?

Let’s work through an example of how a specific time series model can be rearranged into the ADF equation. Consider a model with intercept and linear trend, and 2 lags in the AR equation: \[\begin{align} Y_{t}&=\beta_{0}+\beta_{1} t+Z_{t}\\ Z_{t}&=\phi_{1}Z_{t-1}+\phi_{2}Z_{t-2}+U_{t} \end{align}\] Goal: Rewrite these equations in the form of the ADF equation, derive \(\beta_{0}^{*}\) and \(\beta_{1}^{*}\): \[\Delta Y_{t}=\varphi Y_{t-1}+\beta_{0}^{*}+\beta_{1}^{*}t+\psi_{1}\Delta Y_{t-1}+U_{t}\]

Re-express the autoregressive equation in the form \[\Delta Z_{t}=\varphi Z_{t-1}+\psi_{1}\Delta Z_{t-1}+U_{t}\] where \(\varphi = \phi_{1}+\phi_{2}-1\) and \(\psi_{1}=-\phi_{2}\).

\[\begin{align} Z_{t}&=\phi_{1}Z_{t-1}+\phi_{2}Z_{t-2}+U_{t}\\ Z_{t}&=\phi_{1}Z_{t-1}\textcolor{magenta}{+\phi_{2}Z_{t-1}-\phi_{2}Z_{t-1}}+\phi_{2}Z_{t-2}+U_{t}\\ Z_{t}&=\textcolor{blue}{(\phi_{1}+\phi_{2})Z_{t-1}}\textcolor{green}{-\phi_{2}\Delta Z_{t-1}}+U_{t}\\ Z_{t}\textcolor{red}{-Z_{t-1}}&=\textcolor{red}{-Z_{t-1}}+(\phi_{1}+\phi_{2})Z_{t-1}-\phi_{2}\Delta Z_{t-1}+U_{t}\\ \Delta Z_{t}&=\varphi Z_{t-1}+\psi_{1}\Delta Z_{t-1}+U_{t} \end{align}\] where \(\varphi=\phi_{1}+\phi_{2}-1\) and \(\psi_{1}=-\phi_{2}\).

From Step 1 we have \[\textcolor{red}{\Delta Z_{t}}=\varphi \textcolor{blue}{Z_{t-1}}+\psi_{1}\textcolor{magenta}{\Delta Z_{t-1}}+U_{t}.\] Using the trend equation \(Y_{t}=\beta_{0}+\beta_{1}t+Z_{t}\), derive the following: \[\begin{align} \textcolor{red}{\Delta Z_{t}}\;&\textcolor{red}{=\Delta Y_{t}-\beta_{1}}\\ \textcolor{magenta}{\Delta Z_{t-1}}\;&\textcolor{magenta}{=\Delta Y_{t-1}-\beta_{1}}\\ \textcolor{blue}{Z_{t-1}}\;&\textcolor{blue}{=Y_{t-1}-\beta_{0}-\beta_{1}(t-1)} \end{align}\] substituting gives \((\textcolor{red}{\Delta Y_{t}-\beta_{1}})=\varphi(\textcolor{blue}{Y_{t-1}-\beta_{0}-\beta_{1}(t-1)})+\psi_{1}(\textcolor{magenta}{\Delta Y_{t-1}-\beta_{1}})+U_{t}\)

  • Starting from the trend equation \(Y_{t}=\beta_{0}+\beta_{1}t+Z_{t}\), the first lag is: \[\begin{align} Y_{t-1}&=\beta_{0}+\beta_{1}(t-1)+Z_{t-1}\quad\quad\quad (1)\\ \implies \textcolor{blue}{Z_{t-1}}\;&\textcolor{blue}{=Y_{t-1}-\beta_{0}-\beta_{1}(t-1)} \end{align}\]
  • Using equation (1) and the trend equation, we thus know that: \[\begin{align} &&Y_{t}-Y_{t-1}&=(\beta_{0}-\beta_{0})+\beta_{1}(t-(t-1))+Z_{t}-Z_{t-1}\\ &&\Delta Y_{t}&=\beta_{1}+\Delta {Z_{t}}\\ \implies&& \textcolor{red}{\Delta Z_{t}}\;&\textcolor{red}{=\Delta Y_{t}-\beta_{1}}\\ \implies&& \textcolor{magenta}{\Delta Z_{t-1}}\;&\textcolor{magenta}{=\Delta Y_{t-1}-\beta_{1}} \end{align}\]

From Step 2 we have: \[(\textcolor{red}{\Delta Y_{t}-\beta_{1}})=\varphi(\textcolor{blue}{Y_{t-1}-\beta_{0}-\beta_{1}(t-1)})+\psi_{1}(\textcolor{magenta}{\Delta Y_{t-1}-\beta_{1}})+U_{t}\] Simplify this to the form of ADF test equation: \[\Delta Y_{t}=\varphi Y_{t-1}+\textcolor{green}{\beta_{0}^{*}}+\textcolor{teal}{\beta_{1}^{*}}t+\psi_{1}\Delta Y_{t-1}+U_{t}\] where \(\textcolor{green}{\beta_{0}^{*}=\beta_{1}-\varphi\beta_{0}+\varphi\beta_{1}-\psi_{1}\beta_{1}}\) and \(\textcolor{teal}{\beta_{1}^{*}=-\varphi\beta_{1}}\).

\[\begin{align} (\Delta Y_{t}-\beta_{1})&=\varphi(Y_{t-1}-\beta_{0}-\beta_{1}(t-1))+\psi_{1}(\Delta Y_{t-1}-\beta_{1})+U_{t}\\ \Delta Y_{t}&=\beta_{1}+\varphi Y_{t-1}-\varphi\beta_{0}-\varphi\beta_{1} t+\varphi\beta_{1}+\psi_{1}\Delta Y_{t-1}-\psi_{1}\beta_{1}+U_{t}\\ \Delta Y_{t}&=\varphi Y_{t-1}+\beta_{1}-\varphi\beta_{0}+\varphi\beta_{1}-\psi_{1}\beta_{1}-\varphi\beta_{1}t+\psi_{1}\Delta Y_{t-1}+U_{t}\\ \Delta Y_{t}&=\varphi Y_{t-1}+\textcolor{green}{\underbrace{(\beta_{1}-\varphi\beta_{0}+\varphi\beta_{1}-\psi_{1}\beta_{1})}_{\equiv\beta_{0}^{*}}}+\textcolor{teal}{\underbrace{(-\varphi\beta_{1})}_{\equiv\beta_{1}^{*}}}t+\psi_{1}\Delta Y_{t-1}+U_{t}\\ \Delta Y_{t}&=\varphi Y_{t-1}+\textcolor{green}{\beta_{0}^{*}}+\textcolor{teal}{\beta_{1}^{*}}t+\psi_{1}\Delta Y_{t-1}+U_{t} \end{align}\] where \(\textcolor{green}{\beta_{0}^{*}=\beta_{1}-\varphi\beta_{0}+\varphi\beta_{1}-\psi_{1}\beta_{1}}\) and \(\textcolor{teal}{\beta_{1}^{*}=-\varphi\beta_{1}}\).

  • This derivation is intended to show how the ADF test equation follows from a time series model, including:
    • how the lag length is reduced by one, and
    • how the deterministic coefficients differ between the trend equation and ADF test equation.
  • Having seen this once, the details become practically unimportant thereafter.
    • The values of the deterministic coefficients in the ADF test regression are not directly interesting in themselves.
  • The important thing is the specification of an appropriate ADF test equation from a time series model if it has already been specified.
